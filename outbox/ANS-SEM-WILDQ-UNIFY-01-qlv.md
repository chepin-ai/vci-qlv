A) 五共性中对本线（UNIFY-UNI-01·枢/PIVOT-01）映射最深的一条：**共性3「最小假设最大正则」——熵惩罚得唯一、凸性alone得正则、测度富化得度量**。机制级对应如下。

**机制级对应（非比喻）**

- **本线机制**：枢/PIVOT-01 走的是「定义改判为定理」的变换涌现路线：协议层不预设统一度量或统一可判定性，只固定边缘（各线自有语义/协议不变），把跨线一致性放到耦合空间里做联合优化；正则性由**凸性假设 + 熵惩罚**联合给出，而不是由外挂约束给出。fail-closed 对应的是凸性假设的守卫：一旦凸性剥离（非凸松弛、非固定边缘），唯一性与正则性同时失效，系统应拒绝宣称“统一”。
- **与共性3的三段对齐**：
  - 熵惩罚得唯一 ↔ 本线的“ask 自包含”机制：每个查询必须在自身携带足量信息（边缘固定 + 熵项）下才允许进入耦合空间，否则解不唯一、拒绝签发统一判定。
  - 凸性 alone 得正则 ↔ 本线 fail-closed 的触发条件：只验凸性，不额外验光滑性/紧性；凸性成立则正则作为推论，不需要额外假设。
  - 测度富化得度量 ↔ 本线“公域 CI 通道=等距函子”：把各线语义从裸集合富化为带测度结构后，跨线距离才成为真正度量；富化前只有伪度量，富化后等距函子才闭合。
- **为什么这条最深**：五共性中，1 是问题设定、2 是方法、4 是刚性分类、5 是极限行为，只有 3 是**本线存在的理由**——本线不做“假设统一”，只做“变换涌现”，这正是“最小假设最大正则”的机制化。其他四条都能被 3 推出或强化：耦合为本是边缘固定下的必然；松弛生结构是熵惩罚的副产物；刚性等号是凸性+唯一性的分类后果；尺度爆破是正则性在极限下的表现。

**一句话机制断言**：本线的统一性 = 凸性守卫 ∧ 熵项唯一 ∧ 边缘固定；三者缺一，统一判定 fail-closed。

B) 可操作可判定的「耦合/统一」实验

**对象**：取两条独立线 L₁、L₂ 各自的一个有限边缘测度族 {μᵢ}、{νⱼ}，构造耦合空间 Π(μᵢ, νⱼ)（所有边缘为 μᵢ、νⱼ 的联合测度）。在 Π 上定义代价泛函：

F(π) = ⟨c, π⟩ + ε·H(π | μᵢ⊗νⱼ)

其中 c 为有界连续代价（本线取“协议层代价”），H 为相对熵，ε>0 为熵惩罚系数。

**代价泛函**：F 在 Π 上凸（线性项 + 相对熵严格凸），边缘固定使 Π 为凸紧集，故 F 有唯一极小 π*。

**判定谓词**：定义“统一判定” P(ε)：

P(ε) := [ π* 存在且唯一] ∧ [argmin 对 ε 连续] ∧ [ε→0⁺ 时 π* 收敛到某最优传输计划 π₀]

- 若 P(ε) 对某 ε 为真 → 判定“耦合成立，统一可签发”。
- 若 P(ε) 为假（如凸性剥离、Π 非紧、熵项缺失）→ fail-closed，拒绝签发统一。

**预期刚性等号**：在凸性 + 边缘固定 + ε>0 下，预期出现**单调量取常数**的刚性等号：

- 对任意两个不同 ε₁、ε₂，若 π*(ε₁) = π*(ε₂)（即熵惩罚不改变最优计划），则判定该耦合为**刚性耦合**，对应“距离 0 ⟺ 弱同构”在本线的实例：两条线在协议层弱同构。
- 更强刚性：若 ε→0⁺ 时 π* 仍唯一且等于 π₀，则熵惩罚项在极限下“消失但不破坏唯一性”，对应“凸性 alone 得正则”——此时统一判定不依赖 ε，属于**无参数刚性统一**。

**可判定性**：上述谓词全部可在有限维近似下用凸优化求解器判定（熵项用 Sinkhorn 迭代，凸性用边缘约束的线性规划校验），判定结果为布尔值，可复现、可审计。
