## (a) 四范式碰撞图的同构判定

**意见：pass（成立，但需标注同构的层级）**

- **P1（区间算术证书）↔ P3（形式化证明助手）**：两者在"构造性见证 + 机器可核"层面同构成立。区别在于 P3 的 TCB 是逻辑内核，P1 的 TCB 是浮点语义+区间库。此差异恰好被 M5 覆盖，不构成反例。
- **P2（SAT 证明证书）↔ P1/P3**：DRAT/LRAT 的可核性依赖求解器不可信假设，与 P1 的"包络可重算"、P3 的"内核重放"同构，属证书化范式的三个实例。
- **P4（PINN 失败模式）作为负向锚**：将其放入"碰撞图"而非"反例图"是准确的处理——P4 提供的是 schema 机检与 fp 互锚所要排除的模式空间（残差下降但解非法、正则化掩盖不可行性等），与 M4 退火路径形成对偶。

**保留意见**：四者同构仅在"证书—检查器"抽象层成立，在语义层（区间 vs 布尔 vs 类型论 vs 损失面）不同构。建议图中显式标注"同构层级 = 证书-检查协议层"，避免被误读为语义等价。**该项不降级。**

## (b) M4 / M5 / M6 入册为洞见级镜像律

**意见：M4、M6 = pass；M5 = pass（附修订条件）**

- **M4 延拓律**：curriculum ≡ 退火 ≡ 同伦的等价在"参数化路径 + 路径上不变量保持"层面成立。作为洞见级镜像律够格。**pass。**
- **M6 审计锚律**：内容寻址作为第三方复核前置是必要不充分条件——内容寻址保证"同一性"，不保证"可复核性"（如证书格式私有则寻址无意义）。建议表述为"内容寻址 + 格式公开 + 检查器公开"三者合取才是前置。按现表述入册会留下漏洞。**pass，附此限定。**
- **M5 TCB 最小化律**：核心命题（求解器不可信 + 小型检查器 + 检查器须被检查）方向正确，但"检查器须被检查"若不限定递归深度，会导致无穷回归——实际上工程实践中检查器本身只能被更小的元检查器抽查，或被形式化验证一次后冻结。**入册前须补一条终止条件**（例如："检查器须被至少一个独立实现或形式化验证覆盖，且该覆盖不再要求同类检查器"）。**修订后可 pass。**
